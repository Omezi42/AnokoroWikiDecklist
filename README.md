# あの頃の自作TCG デッキ表ジェネレーター（AI版）

カードゲーム「あの頃の自作TCG」のデッキ編成画面のスクリーンショットを、Gemini AIで解析し、atwiki用のデッキ表を自動生成するツールです。

## 🚀 使い方

1. **[デッキ表ジェネレーター](https://omezi42.github.io/AnokoroWikiDecklist/)** を開く
2. デッキ編成画面のスクリーンショットをファイル選択、または `Ctrl+V` で貼り付け
3. 「AIで画像を解析して表を生成する」をクリック
4. 生成されたatwiki用テーブルをコピーして貼り付け

> **💡 ヒント**: APIキーは組み込み済みなので、設定なしでそのまま使えます。
> レート制限に達した場合は、自分のAPIキーを設定することもできます（ページ上部のオプションから）。

## 🛠 技術仕様

- **フロントエンドのみ**で動作（サーバー不要）
- **Gemini 2.5 Flash** を使用した画像認識
- カード名リストと照合して**表記ゆれを自動補正**（レーベンシュタイン距離）
- GitHub Pagesでホスティング

## 📋 出力形式

atwiki形式のテーブルが生成されます：

```
|~カード名|~枚数|
|[[カード名A]]|3|
|[[カード名B]]|2|
```

## ⚠️ 注意事項

- 画像の品質によって認識精度が変動します
- カード名リストにない新規カードは「不明:」として出力されます
- 多くの人が同時に使うとレート制限に達する場合があります。その際は自分のAPIキーをご利用ください
